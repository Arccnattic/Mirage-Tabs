# Mirage-Tabs
Browser extension that disguises chosen tabs as a fake New tab, document, spreadsheet, inbox or error page. Swaps the title and icon, mutes media, and restores the real page when you type your unlock word. Works on Chromium browsers (Edge, Chrome, Brave).

## Features
- Hides only the sites you choose, or any tab you pin
- Fake covers: New tab, document, spreadsheet, email inbox, PDF, encyclopedia article, 404, "can't reach this page"
- Swaps the tab title and favicon while hidden
- Pauses and mutes media while hidden
- Type your unlock word to restore the real page
- Alt+X panic shortcut hides the current tab instantly
- Optional idle auto-hide
- Many themes for the fake New tab, plus custom backgrounds

## Install (manual)
1. Download the latest zip from the Releases page and unzip it.
2. Open `edge://extensions` or `chrome://extensions`.
3. Turn on Developer mode.
4. Click **Load unpacked** and select the unzipped folder.

## Privacy
Settings are stored in your browser's sync storage. Nothing is collected or
sent anywhere. See PRIVACY.md.
