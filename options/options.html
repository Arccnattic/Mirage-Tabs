Mirage Tabs

Which tabs get hidden

Other tabs are never touched. To hide just one tab, tick “Hide only this tab” in the toolbar popup, or press Alt+X on it (change the shortcut at edge://extensions/shortcuts).

Unlock & search

Case doesn't matter. If left empty, clicking the page restores it instead. This is a convenience lock against casual glances, not real security: anyone using your browser profile could find the word.

Tab disguise

If the site's icon still shows in the tab strip, try “Globe”: a visible icon is accepted by the browser more reliably than an invisible one.
